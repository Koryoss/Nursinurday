# 1단계. 내부 기록으로 최소 항목 선정

## 목적

9주 내부 기록에서 “기록할 수 있는 모든 것”을 외부 참여자에게 요구하지 않고, 주간 회고와 진료 질문 준비에 실제로 필요한 최소 항목만 남긴다. 이 단계에서는 새로운 외부 참여자나 실제 건강정보를 수집하지 않는다.

## 선정 원칙

각 후보 항목을 다음 네 질문으로 평가한다.

1. 이 값이 없으면 주간 회고나 사용자 질문이 달라지는가?
2. 사용자가 하루 1회 부담 없이 답할 수 있는가?
3. 더 덜 민감한 대체항목으로 같은 목적을 달성할 수 있는가?
4. 수집 목적, 보관기간과 결과 화면을 사용자에게 설명할 수 있는가?

## 후보 변수 사전

| 구분 | 후보 항목 | 수집 방식 | 필요성 판정 |
| --- | --- | --- | --- |
| 자동 | 기록일시 | 기록 시 자동 저장 | 유지: 시간 흐름 구성에 필요 |
| 필수 후보 | 오늘 가장 신경 쓰인 불편 | 사용자가 항목 선택 | 유지 여부를 내부 시나리오로 확인 |
| 필수 후보 | 불편 정도 | 0~10 자기평가, 임상 기준 아님 | 척도 이해도와 부담 확인 후 결정 |
| 필수 후보 | 수면 체감 | 짧은 선택형 질문 | 당일 맥락 설명에 필요한지 확인 |
| 선택 | 활동·일정 부담 | 낮음·보통·높음 또는 건너뛰기 | 질문형 문구와 접근성 확인 |
| 선택 | 환경·생활 태그 | 소음, 붐빔, 이동, 기온차 등 직접 선택 | 원인 해석 없이 회상 단서로만 사용 |
| 선택 | 짧은 메모 | 한두 문장 또는 미입력 | 원문 보존, AI 입력 거부 가능 |
| 주간 | 요약이 내 기록과 맞는가 | 맞음·수정 필요·모르겠음 | 요약 정확성과 사용자 통제 평가 |
| 주간 | 다음 진료에서 묻고 싶은 점 | 선택 또는 직접 작성 | 진료 준비 가치 확인 |
| 운영 | 시작·완료·소요시간·중단 | 건강내용과 분리 저장 | 입력 부담과 이탈 개선 |

## 제외 원칙

- 원시 GPS, 상시 음성, 연락처, 통화기록
- 광고·프로파일링 목적 정보
- 진단명 추정, 정상·비정상 또는 중증도 판정용 항목
- 당장 결과 화면이나 평가에 사용하지 않는 “혹시 몰라서” 수집하는 항목
- 의료진 판단 없이 치료·재활 행동을 추천하기 위한 항목

## 실행 절차

1. 기존 기록 항목을 변수명·질문·형식·사용 화면별로 펼친다.
2. 각 항목이 어떤 회고 문장이나 평가값에 사용되는지 연결한다.
3. 사용처가 없는 항목은 삭제 후보로 표시한다.
4. 가상 사용자 10개 시나리오에서 항목을 제거해도 핵심 회고가 유지되는지 확인한다.
5. 하루 1회 기준 2~3분 안에 완료 가능한 최소안과 선택항목을 분리한다.

## 완료 기준

- 필수항목과 선택항목이 분리된 변수 사전 v1
- 모든 항목에 수집목적·보관구분·화면 사용처가 기재됨
- 원시 위치·상시 음성·연락처가 포함되지 않음
- 가상 시나리오 기준 기록과 확인을 합쳐 2~3분 내 완료 가능
- 삭제한 항목과 삭제 이유를 의사결정 로그에 보존
