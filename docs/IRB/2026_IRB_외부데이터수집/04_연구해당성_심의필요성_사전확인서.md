# 4단계. 연구 해당성·심의 필요성 사전확인서

## 목적

외부 참여자를 모집하기 전에 활동의 목적, 자료, 분석과 공개 범위를 기관 담당부서에 제출해 연구 해당성과 필요한 심의 절차를 서면으로 확인한다. 팀이 스스로 “연구가 아니다” 또는 “면제다”라고 판단하지 않는다.

## 사전확인 요약서

### 1. 활동명

진료 사이의 건강·생활 기록을 정리하는 비진단형 데이터 에이전트의 최소수집·사용성 파일럿

### 2. 주관자

- 성명: 정유진
- 소속: 서울대학교 간호대학 학부생
- 지도·책임자: [확정 필요]

### 3. 목적

하루 1회 최소기록의 실행 가능성, 주간 회고의 이해·수정 가능성, 기록 부담과 진료 질문 준비 과정을 확인한다. 질환 진단, 예후 예측, 치료효과 검증은 목적이 아니다.

### 4. 참여자와 모집

- 50대 이상 성인 5~10명
- 모집경로: [지인 모집/기관 협력/온라인 모집 중 확정 필요]
- 사례 또는 보상: [금액·지급조건 확정 필요]
- 취약성·관계에 따른 참여압력 방지: [방안 확정 필요]

### 5. 절차와 자료

- 4~6주, 하루 1회 2~3분 기록
- 선택형 증상·수면·활동·생활 태그와 선택 메모
- 주간 회고 확인·수정과 진료 질문 선택
- 이용 로그와 사용성 설문·면담
- 원시 위치·상시 음성·연락처 미수집

### 6. 분석과 공개

- 기록완료, 미응답, 중도중단, 과업시간, 사용성, 요약 수정률을 집계
- 개인별 진단·예측 또는 집단 효과 검정은 수행하지 않음
- 2026 IRB/DRIVE/CO-SHOW 발표, 보고서 또는 후속 논문 활용 가능성: [범위 확정 필요]
- 공개자료는 집계 결과와 가상 시연자료를 원칙으로 함

### 7. 데이터 관리

- 식별정보와 내용자료 분리
- 접근권한, 암호화, 보관기간, 삭제·철회 처리계획 첨부
- 데이터 처리 서비스와 국외 이전 여부: [확인 필요]

## 기관에 요청할 판단

1. 이 활동이 인간대상연구에 해당하는가?
2. 사전 심의, 심의면제 확인, 또는 다른 기관 절차 중 무엇이 필요한가?
3. 학생 단독 수행이 가능한가, 지도·책임연구자가 필요한가?
4. 가상데이터 UI 점검 결과를 대회에서 사용할 경우 검토가 필요한가?
5. 외부 건강·생활 기록과 면담을 대회·논문에 함께 활용하려면 어떤 동의가 필요한가?
6. 모집문, 보상, 중도철회, 데이터 보관기간에 필요한 기준은 무엇인가?

## 단계별 의사결정

| 활동 | 진행 조건 |
| --- | --- |
| 내부 원자료 검토와 가상데이터 개발 | 외부 개인정보 없이 내부 개발로 진행 |
| 가상데이터 UI 점검 | 기관 판단이 필요한 활용 범위를 확인하고 안내·동의 적용 |
| 외부 건강·생활 기록 수집 | 모집 전에 기관의 서면 판단과 필요한 승인 완료 |
| 대회·발표에 실제 참여자료 사용 | 동의 범위와 승인된 공개계획 안에서만 사용 |
| 논문·학술발표로 확장 | 연구계획 변경 또는 신규 검토 필요 여부를 사전 확인 |

## 제출 첨부물

- 최소수집 프로토콜
- 참여자 안내·동의문 초안
- 모집문과 보상안
- 변수 사전과 화면
- 데이터 흐름·접근권한·보관·삭제계획
- 위험 신호 대응과 금지표현 규칙
- 분석·발표·후속 활용 계획

## 진행 게이트

외부 모집 공고, 계정 생성, 실제 건강·생활 기록 수집은 기관의 서면 판단과 필요한 승인 문서가 확보된 뒤 시작한다.
