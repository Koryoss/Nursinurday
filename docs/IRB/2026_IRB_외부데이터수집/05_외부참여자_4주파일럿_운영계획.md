# 5단계. 외부 참여자 4주 파일럿 운영계획

> 이 계획은 4단계의 기관 사전확인과 필요한 승인을 받은 범위에서만 시행한다.

## 목표

외부 참여자가 최소기록을 실제로 지속할 수 있는지, 주간 회고가 원기록을 충실히 반영하고 이해·수정 가능한지, 다음 진료 질문 준비에 사용되는지를 확인한다. 증상 개선이나 치료효과를 입증하지 않는다.

## 기본 설계

- 규모: 5~10명
- 기간: 4주 기본, 승인 범위와 운영상 필요에 따라 최대 6주
- 기록: 하루 1회 기본, 선택적 추가기록 1회
- 주간 회고: 주 1회
- 종료 점검: 사용성 설문과 반구조화 면담
- 기기: 스마트폰만으로 참여 가능, 웨어러블은 별도 선택동의가 있을 때만 사용

## 운영 일정

### 준비주

- 승인 문서·모집문·동의문 버전 고정
- 가상계정으로 전체 흐름과 삭제 기능 점검
- 참여자 코드 생성과 식별정보 분리
- 위험 신호 안내와 담당자 연락경로 확인

### 0주차

- 안내와 동의 확인
- 계정 생성, 기록·수정·삭제 실습
- 진단·치료 도구가 아니라는 이해 확인
- 알림시간과 접근성 설정

### 1~3주차

- 하루 1회 최소기록
- 주 1회 회고 확인·수정
- 기술오류와 기록부담만 지원하고 건강상태를 해석하지 않음
- 중단 의사와 불편 여부를 정기 확인

### 4주차

- 마지막 주간 회고
- 사용성 설문과 면담
- 데이터 활용·보관·삭제 선택 재확인
- 참여 종료와 문의경로 안내

## 평가항목

| 평가영역 | 지표 | 해석 |
| --- | --- | --- |
| 실행 가능성 | 예정일 대비 기록완료일, 중도중단 | 외부 사용자가 지속 가능한지 확인 |
| 부담 | 기록·회고 소요시간, 건너뛴 항목, 알림 거부 | 최소수집 항목과 빈도 개선 |
| 정확성 | 원기록에 없는 내용 추가율, 날짜·출처 일치 | 에이전트 출력의 충실성 확인 |
| 사용자 통제 | 요약 수정·삭제, AI 미사용 선택 | 사용자가 결과를 통제하는지 확인 |
| 이해도 | 진단·원인·예측으로 오해한 비율 | 문구와 화면의 안전성 개선 |
| 사용자 가치 | 회고 확인, 질문 선택·수정·내보내기 | 진료 준비 과정에서의 활용 확인 |
| 안전 | 금지표현 발생, 위험 신호 안내의 작동 | 의료진·외부자원 연결 우선 확인 |

## 측정 시점과 과제

| 시점 | 측정 내용 |
| --- | --- |
| 시작 전 | 현재 기록 방법과 부담을 질문한다. 가상자료에서 한 주의 변화를 설명하고 진료 질문을 만드는 과제를 수행한다 |
| 사용하는 동안 | 기록 시간과 완료 여부 및 중간에 멈춘 항목을 확인한다 |
| 1주차 종료 | 기록이 얼마나 쉬웠는지 5점으로 질문한다. 가장 불편한 점을 한 가지 적게 한다 |
| 4주차 종료 | 시작 전과 같은 형식의 설명 과제와 질문 준비 과제를 수행한다. 종료 면담을 진행한다 |

자기설명 과제는 한 주의 변화 한 가지를 말할 수 있는지 확인한다. 근거가 되는 날짜나 상황을 찾는지도 본다. 기록된 사실과 자신의 생각을 구분하는지도 살펴본다. 각 항목은 수행 여부만 확인한다. 건강상태나 능력의 등급으로 해석하지 않는다.

진료 준비 과제는 질문 한 가지를 만들고 근거가 되는 원기록을 찾는 과정이다. 3분 안에 수행할 수 있는지 확인한다. 진료의 질이나 치료효과를 평가하지 않는다.

삶의 질은 이 파일럿의 평가항목이 아니다. 기관 검토를 마친 후속 12주 연구에서 한국어 WHOQOL-BREF를 사용한다. 주된 불편에 따라 사용 조건을 확인한 한국어판 DHI 또는 K-THI를 함께 사용한다.

## 중단·대응 기준

- 참여자가 중단을 요청하면 추가수집을 즉시 멈춘다.
- 개인정보 노출이나 권한 오류가 의심되면 신규수집을 중단하고 영향 범위를 확인한다.
- AI가 진단·예후·처방 표현을 생성하면 해당 출력을 사용자에게 제공하지 않고 원인을 검토한다.
- 참여자가 즉각적인 도움이 필요하다고 느끼는 상황에서는 앱 분석보다 119, 담당 의료진 또는 적절한 자원 안내를 우선한다.
- 계획과 다른 자료를 새로 수집해야 한다면 먼저 변경 검토 필요성을 확인한다.

## DRIVE 제출용 산출물

- 개인을 식별하지 않는 참여 흐름과 집계지표
- 최소수집 전후의 문항·화면 변화
- 사용자 오해·수정 사례를 비식별 주제로 정리한 결과
- 데이터 품질·권한·출처 추적 시연
- 외부 사용성 근거로 수정된 MVP
- IP 후보요소와 사업모델 검증에 연결되는 학습 목록

실제 개인 건강기록, 화면 캡처, 원문 메모는 대회 발표자료에 포함하지 않는다. 시연은 가상데이터를 사용한다.
