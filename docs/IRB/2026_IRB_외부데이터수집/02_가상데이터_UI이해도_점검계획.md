# 2단계. 건강정보 없는 UI 이해도 점검

## 목적

실제 증상이나 생활기록을 받기 전에, 가상의 인물과 가상데이터만 사용해 50대 이상 사용자가 기록·주간 회고·수정·삭제 흐름을 이해하는지 확인한다.

## 참여와 자료 범위

- 권장 규모: 3~5명
- 사용 자료: 가상의 이름, 날짜, 증상값, 메모
- 받지 않는 자료: 참여자의 질환명, 증상값, 진료내역, 위치, 음성, 연락처
- 참여자에게 요구하지 않는 것: 자신의 경험을 입력하거나 공개하는 행위

사람을 대상으로 반응과 수행자료를 체계적으로 수집·분석하거나 대회·발표 자료로 사용할 계획이 있다면, 건강정보를 받지 않더라도 4단계 사전확인 대상에 포함한다.

## 점검 과업

1. 서비스가 진단이나 처방을 제공하지 않는다는 설명을 읽는다.
2. 가상 인물의 하루 기록을 입력한다.
3. 가상 주간 회고에서 원기록과 요약을 비교한다.
4. 틀린 요약 한 곳을 찾아 수정한다.
5. 결과의 출처와 “원인이 아닌 동반 양상” 안내를 찾는다.
6. 기록을 내보내고 삭제하는 위치를 찾는다.
7. 도움이 필요한 상황에서 의료진·외부자원 안내를 찾는다.

## 수집할 비건강정보

- 과업 완료 여부
- 과업별 소요시간
- 잘못 선택하거나 되돌아간 화면
- 이해되지 않은 단어
- 글씨 크기·버튼·알림에 대한 의견
- “이 결과가 진단으로 보였는가”에 대한 이해 확인

## 진행 안내 문구

> 이 점검은 실제 건강상태를 묻지 않습니다. 화면에는 모두 가상의 정보가 사용됩니다. 본인의 증상이나 진료경험을 입력하지 않아도 되며, 원하지 않으면 언제든 중단할 수 있습니다.

## 완료 기준

- 핵심 과업 대부분을 진행자 설명 없이 완료
- 진단·처방 서비스로 오해하는 표현이 확인되면 수정
- 요약 수정·삭제·출처 확인 경로를 참여자가 찾을 수 있음
- 평균 수행시간보다 막힘 지점과 오해 원인을 우선 기록
- 화면 개선사항을 반영한 최소수집 UI v2

## 산출물

- 과업 관찰표
- 용어·접근성 문제 목록
- 변경 전후 화면과 의사결정 기록
