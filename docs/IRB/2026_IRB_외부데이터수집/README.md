# 2026 IRB 외부 데이터 수집 5단계 문서

## 전체 원칙

외부 데이터를 빨리 많이 모으는 것이 목표가 아니다. 가장 적은 자료로 사용자 가치와 데이터 에이전트의 정확성을 확인하고, 단계마다 다음 단계로 넘어갈 조건을 검증한다.

| 단계 | 실제 건강정보 | 핵심 질문 | 다음 단계 조건 |
| --- | --- | --- | --- |
| 0. 기존 자료 공개범위 확인 | 새로 수집하지 않음 | 9주 자료에서 무엇을 신청서에 쓸 수 있는가? | 자료 제공자가 항목별 공개 범위를 확인하고 원자료를 분리 보관 |
| 1. 내부 최소항목 선정 | 새로 수집하지 않음 | 꼭 필요한 데이터는 무엇인가? | 변수 사전·제외 로그 완성 |
| 2. 가상데이터 UI 점검 | 수집하지 않음 | 처음 보는 사람이 이해·수정·삭제할 수 있는가? | 오해·접근성 문제 수정 |
| 3. 프로토콜·안내 초안 | 수집하지 않음 | 무엇을 왜 얼마나 모으고 어떻게 보호할 것인가? | 수집·보관·철회·안전계획 확정 |
| 4. 연구 해당성 사전확인 | 수집하지 않음 | 어떤 기관 절차와 승인이 필요한가? | 서면 판단과 필요한 승인 확보 |
| 5. 외부 파일럿 | 승인·동의 범위만 수집 | 4주간 지속·이해·수정·활용 가능한가? | 집계 결과와 제품개선 증거 확보 |

## 대회와의 연결

- Data: 1·3단계에서 변수와 권한을 확정
- Research: 2·4·5단계에서 전향적 검증과 재현성 확보
- IP: 단계별 의사결정·데이터 역할·안전규칙을 핵심 기술요소로 정리
- Value: 2·5단계에서 이해·수정·질문 활용을 확인
- Entrepreneurship: 5단계 결과를 초기 사용자·기관·사업모델 검증에 연결

2026 IRB 경진대회와 기관의 연구윤리 심의는 서로 다른 절차다. 대회에 참가하거나 선발되었다는 사실이 외부 참여자 모집·건강정보 수집 승인을 대신하지 않는다.
