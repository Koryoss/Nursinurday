# 2026 IRB 9주 내부 설계 참고기록 분석 재현서

## 1. 자료와 단위

- 원표: `Nursinurday/1인 분석/증상표.xlsx`
- 기존 결과: `Nursinurday/1인 분석/CareFlow_Nof1_분석리포트.docx`
- 기간: 2026.4.20~6.21, 9주
- 자료 제공자: 서비스 구체화에 도움을 준 실제 환자인 지인 1명
- 기록 방식: 자료 제공자가 매주 지난 일주일의 흐름을 되짚어 시간대별 추산값과 주간 메모를 표로 정리
- 분석 단위: 5개 증상의 주별 요약값, 변수별 n=9

이 자료는 정식으로 모집한 연구참여자의 전향적 측정자료가 아니다. 환자의 실제 생활경험을 바탕으로 어떤 기록 항목·시간 구조·회고 화면이 필요한지 구체화하기 위해 도움받은 내부 제품 설계 참고자료다. 신청서·발표·시연에는 개인을 알아볼 수 있는 원기록을 포함하지 않는다.

이 문서는 내부 재현용이므로 정확한 기간과 분석값을 보관한다. 외부 제출본에는 자료 제공자가 항목별로 허용한 내용만 옮긴다. 원표와 주간 메모 원문 및 정확한 날짜는 공개하지 않는다. 시연에는 가상자료만 사용한다. 서명한 공개 범위 확인서는 저장소 밖에 보관한다.

## 2. 236개와 결측치 판정

`236개`는 작성자가 수동으로 집계한 항목별 추산값이며 앱 제출 횟수나 독립 관측 횟수가 아니다. 현재 원표에서 5개 핵심 증상 행의 순수 숫자 셀은 230개다. 원표에는 별도로 식사 행의 숫자, `수면/숫자` 혼합 문자열, ○·△ 등의 범주형 표기가 있다.

따라서 236과 230의 차이 6개를 결측치로 판정하지 않는다. 24개 시간칸도 사전에 모두 입력하도록 정한 측정 시점이 아니므로, 빈칸은 현재 단계에서 ‘계획된 측정의 누락’이 아니라 ‘값이 기입되지 않은 시간칸’이다.

신청서 표기는 다음으로 고정한다.

> 작성자 수동 집계 항목별 추산값 236개. 236회의 앱 제출 또는 독립 측정을 뜻하지 않음.

## 3. 상관분석 복원 결과

내부 리포트의 주차별 추이 그림에 사용된 9개 주별 요약값을 복원해 전체 상관행렬을 다시 계산했다. Pearson 적률상관계수를 사용했을 때 리포트 행렬의 모든 값이 소수 둘째 자리까지 일치했으며, Spearman 상관으로는 재현되지 않았다.

확정적으로 복원된 분석 규칙은 다음과 같다.

1. 각 증상의 9개 주별 요약값으로 Pearson 상관계수를 계산한다.
2. 주 단위 자료에는 변수별 9개 값이 모두 있어 상관계산 단계의 결측은 없다.
3. 반복측정의 자기상관이나 다중비교는 별도로 보정하지 않은 탐색 분석이다.

현재 원표를 새로 계산할 때는 각 주에 입력된 숫자만 산술평균하고 빈 시간칸을 제외했다. 그러나 기존 리포트 요약값 4곳이 이 계산과 달라, 기존 리포트가 주평균을 만들 때 적용한 빈칸 처리 외의 수동 보정 또는 이전 값 사용 여부는 완전히 복원되지 않았다.

리포트 기재값은 다음 두 조합이다.

- 걷기 불안–머리아픔: Pearson r=0.80, n=9
- 걷기 불안–떨림: Pearson r=0.73, n=9

## 4. 원표와 기존 리포트의 차이

리포트 그림의 주별 요약값 중 4곳은 현재 원표의 숫자형 값만 빈칸 제외 평균한 결과와 다르다. 특히 걷기 불안의 첫 주 요약값 차이 때문에 현재 원표를 직접 재계산하면 걷기 불안–머리아픔은 약 0.77, 걷기 불안–떨림은 약 0.79가 된다.

따라서 기존 0.80·0.73은 **현재 원표에서 새로 계산한 값**이 아니라 **내부 리포트에 사용된 당시 주별 요약값의 Pearson 결과**로 구분한다. 신청서에서는 탐색적 동반 양상의 보조 근거로만 사용하며 원인·예측·일반화 근거로 해석하지 않는다.
