# CareFlow — 제품·측정 단일 기준 (SPEC)
> Single Source of Truth. 모든 코드·카피·DB는 이 문서와 〈지원/CareFlow_사회복귀지표_설계안.docx〉를 따른다.
> 최종 업데이트: 2026-06 (설계안 Step1–3 + 부록 A–F 반영). 웹(Next.js)·모바일(RN)·Codex 공통 기준.

## 0. 미션 / 절대 경계 (하드룰)
- 미션: 이명·어지럼 환자가 증상을 안고도 일상·사회로 복귀(live better)하도록 돕는 **비의료기기 자기관찰 도구**.
- 금지: 진단·중증도 판정·예후 예측·치료/재활(VRT 등) 처방.
- 허용: 상태 인식 + 생활 설계 보조. 동사는 "고려해보세요 / 함께 볼까요". 단정·감정규정 금지, 질문형. 상관 ≠ 인과.
- 안전망: 위험 신호(HADS 고점, 급성 악화 등) → 지표 대신 의료진·외부자원 연계 우선.

## 1. 4축 + 안전 레이어
몸 · 감정 · 관계 · 의미 (+ 위기 감지 안전망).

## 2. 사회복귀 지표 (설계안 Step1) — 개인 7일 기준선 대비 3단계(낮음/보통/높음)
- 오늘의 여유(HRV) · 걸음 안정도(IMU) · 활동 범위(융합) · 환경 민감도.
- **절대 임상 컷오프·진단명·예후 확률 산출 금지.** 모두 본인 기준선 대비 상대값.

## 3. 측정 규격 (부록 F)
- 일일: 몸(어지럼/걷기불안/이명/두통/비문증/기타 0–10) · 감정(불안·긴장 + 선택 감정 신호/기타 감정 신호 0–10) · 관계(이해받음 Y/N) · 수면(취침·기상 + PSQI 3문항) · 환경 태그(소음/기온차/붐빔) · 의미(주1 메모).
- 주1회 체크인: DHI · THI · HADS · VSS-SF (추세용, 판정 아님).
- 기록 시점: 4구간(아침/오후/저녁/취침 전) + 응급 시 즉시. 척도는 “심할수록/강할수록 10에 가깝게”처럼 사용자 친화 문구로 표시한다.

## 4. 화면 (설계안 Step2)
오늘(홈) · 일정 · 추세 · 지표설명 · 기록 · 대화. 와이어: 지원/CareFlow_사회복귀지표_와이어프레임.html.

### 4.1 디자인 토큰 (P3)
- 색: 배경 `#F3F6F1`, 표면 `#FBFCFA`, 카드 `rgba(255,255,255,0.82)`, 본문 `#26312A`, 보조 `#5F6D64`, 흐림 `#8D9A91`, 주색 `#5C7A5E`, 주색 진함 `#3F5F46`, 주의 `#C58F5B`.
- 4축 색: 몸 `#C58F5B`, 감정 `#9B8AC6`, 관계 `#5C7A5E`, 환경 `#4F7F8F`처럼 서로 구분되는 색을 사용한다.
- 폰트: Pretendard 우선, `-apple-system`, `Apple SD Gothic Neo`, `Noto Sans KR`, sans-serif fallback.
- Radius: 카드 16px, 입력 12px, 작은 컨트롤 8-10px, pill 999px, 모바일 쉘 44px.
- Spacing: 4/8/12/16/24/32px 단위. 모바일 화면의 기본 내부 여백은 16-22px.
- 공통 컴포넌트: `Button`은 primary/secondary/ghost, `Card`는 단일 프레임, `Slider`는 0-10 기록용, `Header`는 CareFlow 점 로고 + 화면명 + 우측 액션 구조를 따른다.
- 화면 원칙: 홈·로그인·온보딩·기록·대시보드는 같은 주색/표면/카드 체계를 사용한다. 버터크림·단일 보라/파랑 계열로 분리된 테마를 만들지 않는다.
- 모바일 접근성: 50–60대 사용자를 기본 사용자로 두고 본문 15–16px 이상, 주요 값/라벨 17px 이상, 주요 터치 영역 44px 이상을 유지한다. 임시 이모지·자의적 기호 대신 명확한 텍스트 버튼과 일관된 네이티브 앱형 컨트롤을 우선한다.

## 5. 데이터 원칙
