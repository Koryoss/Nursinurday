# CareFlow 데모 영상 촬영 스크립트 (초안)

작성일: 2026-09-17

## 먼저 — 왜 내가 직접 영상을 못 만드는지

시도해본 방법과 막힌 지점을 그대로 적어둔다.

1. 이 앱(Cowork)의 인앱 브라우저로 `careflow-delta.vercel.app`을 열어볼 수는 있지만, 화면 녹화·GIF
   생성 기능은 없다 — 스크린샷 한 장씩만 가능하고 이어붙일 방법이 없다.
2. 작업 샌드박스(리눅스)에서 Playwright/Chromium을 직접 설치해 자동 녹화를 시도했는데,
   네트워크 아웃바운드가 허용된 도메인 목록으로 제한돼 있어서 Chromium 다운로드 서버
   (`cdn.playwright.dev`)가 403으로 막힌다. ffmpeg는 있지만 녹화할 브라우저가 없다.
3. Claude in Chrome 확장(연결되면 GIF 녹화 가능한 도구가 있음)은 지금 이 세션에 연결돼
   있지 않다 — 사용자가 크롬 확장을 설치·로그인하면 그때는 웹 랜딩 페이지 한정으로
   자동 GIF 녹화를 시도해볼 수 있다.
4. 실제 제품 경험(모바일 Expo 앱)은 애초에 내가 조작할 수 있는 기기가 없다 — 시뮬레이터도
   실기기도 이 환경에는 없다.

그래서 지금 할 수 있는 최선은, 사용자가 직접 화면 녹화 버튼만 누르면 되도록 촬영 순서를
초 단위로 짜두는 것이다.

## 옵션 A — 가장 쉬운 것: 웹 랜딩의 내장 미리보기부터

`careflow-delta.vercel.app`에는 이미 "화면 흐름 미리보기"라는, 요약→추세→기록→알림 4개
화면이 자동으로 전환되는 섹션이 있다(사이트 문구 그대로 "영상처럼 자동으로 전환되는
화면 흐름"). 로그인 없이 누구나 바로 볼 수 있다.

1. Mac에서 Cmd+Shift+5(또는 QuickTime 새로운 화면 기록)로 녹화 시작
2. `careflow-delta.vercel.app` 접속, "화면 흐름 미리보기" 섹션까지 스크롤
3. 한 사이클(약 10~15초) 지나갈 때까지 대기 후 녹화 종료

준비물도 조작도 거의 없어서 신청서에 급하게 붙일 짧은 클립이 필요하면 이게 제일 빠르다.
다만 이건 정적 목업이라 실제 데이터가 움직이는 건 아니다.

## 옵션 B — 실제 제품 데모(모바일 앱), 60~90초 촬영 스크립트

iPhone 화면 녹화(제어센터에서 시작) 또는 시뮬레이터 + QuickTime으로 진행. 아래 순서는
실제 구현된 기능만 담았다(Q4-1 "현재 구현 완료" 목록·코드 확인 기준 — 없는 기능은 넣지 않음).

| 시간 | 화면 | 무엇을 보여줄까 | 비고 |
|---|---|---|---|
| 0–10초 | 대시보드(홈) | 오늘 지표(활동 범위·걸음 안정도 등 band) + 최근 7일 추세 그래프 | "개인 기준선 대비" 문구가 보이게 |
| 10–25초 | 기록 화면 | 몸·감정·관계·의미 4축 체크리스트 입력 → 저장 | Context Assistant 카드("과거 비슷한 기록") 뜨는 순간 강조 |
| 25–40초 | 주간 회고 | 자동 생성된 주간 요약 문장(Summary Assistant) | "관찰됐어요/함께 볼까요" 같은 질문형 문구가 보이게 |
| 40–50초 | 주간 회고 하단 | 진료 질문 준비 — 질문 저장, 저장된 질문 목록 | 실제 구현된 기능, 신청서 Q4-1에도 언급됨 |
| 50–65초 | Apple Watch | "지금 기록하기" 탭 → 잠시 후 아이폰 대시보드에 새 기록 반영 | 워치·폰이 화면에 같이 나오게 투샷으로 찍으면 좋음 |
| 65–75초 | 마무리 | 앱 아이콘/로고, 한 줄 소개 텍스트 | "이명·어지럼·메니에르병 환자를 위한 비의료기기 자기관찰 앱" |

### 촬영 팁
- 워치 자동 센서(심박·소음·움직임) 수집은 오늘 막 코드만 작성했고 Xcode 빌드 검증 전이라,
  이번 영상에서는 "지금 기록하기" 버튼(수동 기록)까지만 보여주는 게 안전하다.
- 위기 감지 안전망(1393 안내)은 실제로 트리거하는 장면을 넣지 않는 걸 권한다 — 민감한
  기능이라 데모에서는 "이런 게 있다" 정도로 문서(신청서 Q4-1)에서만 언급해도 충분하다.
- 신청서·IRB 제출용이면 자막 없이 순수 화면만 찍고, 별도로 이 표의 "무엇을 보여줄까" 열을
  자막이나 내레이션 스크립트로 얹어도 된다.

## 옵션 C — 크롬 확장 연결 시

Claude in Chrome 확장을 설치·로그인하면, 다음 세션에서 웹 랜딩 페이지에 한해 GIF 자동
녹화를 시도해볼 수 있다(클릭 지점 표시·진행바가 자동으로 들어가는 GIF). 모바일 앱 쪽은
이 방법으로도 안 된다 — 여전히 사용자가 직접 찍어야 한다.
