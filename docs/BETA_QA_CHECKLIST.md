# CareFlow Beta QA Checklist

SPEC 기준: 비의료기기 자기관찰 도구. 진단, 예후, 중증도 판정, 치료·재활 처방 표현은 노출하지 않는다.

## 1. 50-60대 사용성

- 홈에서 `오늘의 지표`, `오늘 저장된 기록`, `걸음 안정도`, `활동 범위`를 첫 화면에서 읽을 수 있다.
- 기록 화면에서 `기록 날짜`, `기록 시점`, `일일기록`, `수면` 라벨이 작게 보이지 않는다.
- 주요 터치 영역은 손가락으로 누르기 쉬운 크기다.
- 하단 탭 `기록`, `알림`은 글씨와 아이콘이 함께 보여 의미가 바로 읽힌다.
- 달력에서 토요일까지 잘리지 않고 한 달 전체가 보인다.
- 수면 시간 선택은 4개 칸 숫자 선택 방식으로 이해된다.

## 2. 기록 E2E

- 이메일 로그인 후 홈으로 진입한다.
- `기록`으로 이동해 날짜와 시점을 선택한다.
- 몸: 어지럼, 이명을 입력하고 선택 증상을 추가·삭제할 수 있다.
- 감정: 기본 감정과 선택 감정을 추가·삭제할 수 있다.
- 관계: 사람들과 함께했나요, 고립감을 느꼈나요, 소통이 힘들었나요를 선택할 수 있다.
- 의미: 성취감, 하루의 의미, 계획한 일을 선택하면 저장 후 홈의 오늘 저장된 기록에 `의미`가 보인다.
- 수면: 취침·기상 시간을 선택하고 3문항을 저장할 수 있다.
- 같은 시점 기록이 여러 개여도 홈에서는 같은 키워드별로 묶여 보인다.

## 3. 지표·추세

- 지표 설명은 `개인 최근 기록 대비 관찰`로 보인다.
- 낮음/보통/높음은 정상·비정상 판정처럼 설명되지 않는다.
- 누적 기록 그래프는 시작부터 최근까지 한 흐름으로 보인다.
- 관찰된 연관은 인과 표현 없이 `관찰된 흐름`으로만 표시된다.

## 4. 경계 카피

- 진단명, 예후 확률, 중증도 판정, 치료·재활 처방 표현이 없다.
- 채팅 응답은 관찰 문장과 기록 질문으로 이어진다.
- 위기 신호에서는 기록보다 외부 도움 연결 안내가 먼저 보인다.

## 5. Supabase 확인

- `daily_logs`, `symptom_scores`, `affect_logs`, `affect_scores`, `social_logs`, `context_tags`, `sleep_logs`, `meaning_notes`에 본인 기록만 저장된다.
- 다른 계정으로 로그인했을 때 이전 계정 기록이 보이지 않는다.
- 삭제 UI 사용 시 자식 테이블 기록이 함께 사라진다.
