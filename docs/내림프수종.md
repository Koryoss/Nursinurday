# [[내림프수종]] (Endolymphatic Hydrops)
출처: 메니에르 병태생리 일반 · 2020 inner-ear model · #신경과학 #전정 #메니에르
## 핵심 정의
- 내이 막미로 내 내림프액이 과도하게 축적 → 막미로 팽창
- 메니에르병의 대표적 병리 소견(회전성 어지럼·이명·변동성 난청·이충만감)
- 발작은 예측이 어렵고 시간에 따라 청력 손실·양측화로 진행
