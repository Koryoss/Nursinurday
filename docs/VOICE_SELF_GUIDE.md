# 음성 기록 자체 구현 가이드 (CareFlow)
> 목적: 음성/텍스트 → **기록 초안** → 사용자 **확인** → Supabase 저장.
> 원칙(SPEC §0): 비의료기기. 자동 저장 금지(반드시 확인 단계), 모호하면 점수 추정 금지(질문), 진단/예후/처방 없음.
> 전략: **돈·서버 없이 되는 것부터(Phase 0) → 무료 자체(Phase 1) → STT(Phase 2)** 순서.

---

## 전체 흐름
입력(텍스트 또는 음성) → ① 텍스트화 → ② 규칙/형태소로 항목 추출 → ③ 스키마 매핑 → ④ 숫자 추출 → ⑤ **확인 화면** → 저장

스키마(이미 존재): 몸(symptom_scores) · 감정(affect_logs) · 관계(social_logs) · 환경(context_tags) · 수면(sleep_logs).

---

## Phase 0 — 지금 바로, 키·서버 0 (혼자 가능) ★권장 시작
STT 없이 **텍스트 입력 + 규칙 사전**만으로 시작. 외부 비용·서버 불필요.

**(1) 규칙 사전** — 동의어 → 스키마 키 (JS 객체 하나, 계속 추가 가능)
- 이명: 귀 울림, 삐 소리, 윙, 이명 → `tinnitus`
- 어지럼: 빙빙, 어질, 핑 돎, 균형 → `dizziness`
- 걷기불안: 휘청, 비틀, 걷기 무서움 → `gait`
- 두통: 머리 아픔, 띵, 지끈 → `headache`
- 감정: 불안/초조→`anxiety`, 긴장→`tension`, 예민/짜증→`irritation`, 두려움→`fear`, 멍함→`numbness`
- 관계: 이해받음/혼자 등 → `social.understood`
- 환경: 시끄러움→`noise`, 기온차→`weather_change`, 사람 많음→`crowded`
- 시점: 아침/오전→morning, 오후→afternoon, 저녁→evening, 자기 전→before_sleep, 발작/응급→attack

**(2) 숫자 추출**
- "어지럼 7" 처럼 **명시 숫자만** score로.
- "심했다/조금" 같은 정도어는 **추정 금지** → `needsConfirmation`에 넣고 "0–10 중 어디에 가까웠나요?" 질문.

**(3) 확인 화면** — 초안을 보여주고 사용자가 수정/점수 입력 후에만 저장.

→ 이 단계는 **순수 JS**라 careflow 안에서 바로 구현. 비용 0.

---

## Phase 1 — 형태소 분석 (무료·자체, 파이썬 서버 1대 필요)
규칙 사전만으로 놓치는 표현을 잡고 싶을 때.

- 라이브러리(무료, 키 불필요): **KoNLPy(Okt/Komoran), Mecab-ko, soynlp** — 전부 파이썬.
- 한계: 파이썬이라 **Node 전용 Vercel 함수에선 못 돌림** → 작은 파이썬 서버 필요.
- 돌릴 곳(무료 티어): **Render / Railway / Fly.io** 중 하나에 파이썬 API 한 개 배포 → careflow에서 호출.
- 흐름: 텍스트 → (파이썬 형태소 API) → 핵심 형태소 → 규칙 사전 매핑(Phase 0 재사용).

→ 비용 0(무료 티어), 단 "파이썬 API 1개 배포"라는 작업이 추가.

---

## Phase 2 — STT (음성→텍스트)
- **쉬움(권장)**: **보유한 OpenAI Whisper API** 사용. 키 이미 있음, 분당 약 $0.006로 사실상 소액. careflow API에서 오디오 받아 Whisper 호출 → 텍스트.
- **완전 무료(인프라 부담)**: 오픈소스 **whisper.cpp / faster-whisper** 자체 호스팅 → 비용 0이나 CPU/GPU 서버 필요(Vercel 부적합, Render/Railway/직접 서버).
- 비추천: 브라우저 Web Speech API(모바일·한국어 신뢰도 낮음).

## 비의료기기 경계 체크 (필수)
- 초안은 절대 자동 저장 X → **확인 화면 거쳐야 저장**.
- 정도어("심했다") → 점수 **추정 금지**, 질문으로.
- 진단/예후/처방 문구 생성 금지. 카피 "관찰/함께 볼까요" 유지.
- 추출 실패 항목은 비워두고 사용자가 채우게.
